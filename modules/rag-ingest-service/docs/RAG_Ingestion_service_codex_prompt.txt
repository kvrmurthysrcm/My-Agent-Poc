You are working inside a Python FastAPI project for a RAG ingestion service.

Reference document:
docs/RAG_Ingest_Service_Action_Plan_v1_1_Updated.docx

Goal:
Implement the /rag/ingest POC based on the reference document.

Primary requirements:

1. Create a FastAPI service with:

   * GET / or GET /ui browser upload interface
   * POST /rag/ingest
   * GET /rag/ingest/jobs/{job_id}
   * GET /health

2. POST /rag/ingest must:

   * Accept multipart/form-data
   * Accept file as binary upload
   * Accept metadata as JSON string
   * Validate file extension, MIME type, and file size
   * Store document/resource metadata
   * Extract document metadata from the uploaded file when available
   * Let request metadata override file metadata
   * Fill missing title, author, language, publisher, description, and published date from file metadata where possible
   * Fall back to the filename as title when no title exists in request metadata or file metadata
   * Create an ingestion job row
   * Return resource_id, job_id, and status immediately
   * Do not wait for text extraction, chunking, or embeddings to finish

3. Implement configurable embedding provider selection.
   Keep embeddings and NLQ/text processing model configuration separate.

   Default local embeddings configuration:

   * EMBEDDING_PROVIDER=ollama
   * EMBEDDING_MODEL=embeddinggemma
   * EMBEDDING_DIMENSION=768
   * OLLAMA_BASE_URL=http://127.0.0.1:11434

   Supported local Ollama embedding alternatives:

   * EMBEDDING_MODEL=nomic-embed-text with EMBEDDING_DIMENSION=768
   * EMBEDDING_MODEL=mxbai-embed-large with EMBEDDING_DIMENSION=1024

   Default local NLQ/text processing configuration:

   * LLM_PROVIDER=ollama
   * LLM_MODEL=mistral:latest

   Use embeddinggemma only for embedding/vector creation. Use mistral:latest for NLQ/text processing.

   OpenAI must remain configurable:

   * EMBEDDING_PROVIDER=openai
   * EMBEDDING_MODEL=text-embedding-3-small
   * OPENAI_API_KEY from environment variable

   Additional local Ollama option:

   * EMBEDDING_MODEL=gemma4

4. Implement Python abstraction similar to Java interface style:

   * Create an EmbeddingProvider abstract base class or Protocol
   * Implement OpenAIEmbeddingProvider
   * Implement OllamaEmbeddingProvider
   * Implement EmbeddingProviderFactory
   * The ingestion worker must depend only on the EmbeddingProvider abstraction, not directly on OpenAI or Ollama classes

5. Implement configurable async backend selection.
   Config value:

   * ASYNC_BACKEND=fastapi_background_tasks
   * ASYNC_BACKEND=db_worker
   * ASYNC_BACKEND=rq
   * ASYNC_BACKEND=kafka

   Create a JobDispatcher abstraction.
   Implement:

   * FastApiBackgroundTaskDispatcher
   * DbWorkerDispatcher
   * RqJobDispatcher
   * KafkaJobDispatcher

   For this POC, fully implement FastAPI BackgroundTasks and DB-backed worker.
   For RQ and Kafka, create clean adapter classes with TODO implementation hooks, config, and method signatures.

6. Implement intelligent chunking:

   * Default strategy: INTELLIGENT_RECURSIVE
   * Default chunk size: 800 tokens
   * Default overlap: 120 tokens
   * Preserve chunk_index, page_start, page_end, section_title, heading_path, token_count, char_count, chunk_hash_sha256

7. Implement file parsing initially for:

   * .txt
   * .pdf
   * .docx
   * .epub

   PDF parser selection must be configurable:

   * PDF_PARSER=pymupdf by default
   * PDF_PARSER=pypdf as fallback
   * Keep the existing pypdf parser code intact
   * Add a PdfParser abstraction, PyMuPdfParser, PyPdfParser, and PdfParserFactory
   * TextExtractionService must depend on the PdfParser abstraction/factory, not hard-code a PDF parser

8. Implement DB layer using:

   * SQLAlchemy 2.x
   * Alembic migrations
   * PostgreSQL
   * pgvector-ready schema

9. Create tables or models based on the document:

   * resources extension fields
   * rag_ingestion_jobs
   * rag_document_extractions
   * rag_document_chunks
   * rag_chunk_embeddings
   * rag_processing_errors

10. Store original uploaded file temporarily.
    After successful chunking and embedding:

* Keep metadata
* Keep SHA-256 hash
* Keep chunks
* Keep embeddings
* Add DELETE_ORIGINAL_FILE_AFTER_INGESTION config and default it to true
* Delete the original uploaded file after successful ingestion when DELETE_ORIGINAL_FILE_AFTER_INGESTION=true
* Keep the original uploaded file for failed jobs so failures can be debugged
* Allow disabling cleanup by setting DELETE_ORIGINAL_FILE_AFTER_INGESTION=false
